# Homepage example

`jaguars-eagles.webp` is an actual TrashTalk output from `reports/preview-e2e-image.jpg`, resized to 640 × 640 and encoded as WebP (quality 85) without changing the artwork. The meme was generated for Jaguars vs. Eagles, rooting for the Jaguars. It contains no user photo. This bundled promotional example is independent of the user-managed shared gallery.
